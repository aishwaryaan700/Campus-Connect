# Campus Connect

Campus Connect is a campus management web application designed to help administrators, educators, and students manage and access academic information through a single platform.

## Objectives

- Manage student and educator records.
- Organize courses and student enrollments.
- Record and view attendance.
- Manage marks and academic information.
- Provide appropriate access to different user roles.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **API:** REST APIs, JSON
- **Database:** MySQL, SQL
- **API Testing:** Postman
- **Version Control:** Git, GitHub

## Project Status

Initial setup and planning.

Features will be implemented and tested incrementally.
