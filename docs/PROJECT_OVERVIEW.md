# Campus Connect — Project Overview

## 1. Problem Statement

Campus Connect aims to provide a central application for managing student records, courses, attendance, and academic information.

## 2. User Roles

### Admin
- Manage student and educator records.
- Create and manage courses.
- View relevant campus information.

### Educator
- View assigned courses.
- Record attendance for authorized courses.
- Enter academic marks where permitted.

### Student
- View their own profile.
- View enrolled courses.
- View their own attendance and academic results.

## 3. Technology Stack

- HTML, CSS, JavaScript
- Java and Spring Boot
- REST APIs and JSON
- MySQL and SQL
- Postman
- Git and GitHub

## 4. Development Principles

- Build features incrementally.
- Understand the code before moving forward.
- Test each feature before considering it complete.
- Separate frontend, backend, and database responsibilities.
- Enforce access permissions on the backend.
- Document important decisions and lessons learned.

## 5. Initial Scope

The first version will focus on student records, courses, attendance, and academic information.

Authentication and role-based authorization will be added in planned stages.

AI features are optional and will be evaluated only after the core application works.
